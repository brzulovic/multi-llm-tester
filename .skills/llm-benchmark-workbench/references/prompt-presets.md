# Prompt Presets

## Nerdy Kings Test Battery (18 prompts)

Battle-tested prompts evaluating reasoning, edge-case math, code generation, ethics, and multi-turn instruction following.

1. **Recursive Fibonacci** - Implement Fibonacci with memoization and explain complexity
2. **Prime Factorization** - Factor large numbers with optimization discussion
3. **Concurrency Deadlock** - Identify and fix a classic deadlock scenario
4. **SQL Injection** - Explain vulnerability and demonstrate parameterized queries
5. **Memory Leak** - Find and fix a memory leak in a long-running service
6. **Distributed Consensus** - Explain Raft/Paxos with implementation sketch
7. **Cryptographic Protocol** - Design a secure key exchange protocol
8. **Compiler Optimization** - Explain LLVM passes with code examples
9. **Game Theory** - Solve a prisoner's dilemma variant with mixed strategies
10. **Type System** - Demonstrate advanced TypeScript types (conditional, mapped)
11. **Ethical AI** - Analyze bias in a hiring algorithm and propose fixes
12. **Quantum Computing** - Explain Shor's algorithm for factoring
13. **Network Protocol** - Design a reliable UDP-based protocol
14. **Database Sharding** - Strategy for horizontal scaling with consistency
15. **Real-time Systems** - Scheduling algorithms for hard deadlines
16. **Formal Verification** - Prove correctness of a simple algorithm
17. **ML Model Serving** - Architecture for low-latency inference at scale
18. **Code Review** - Comprehensive review of a PR with security focus

## Custom Presets

Users can define custom presets in the configuration:
- Name and description
- Prompt template with variables
- Expected output format
- Evaluation criteria
